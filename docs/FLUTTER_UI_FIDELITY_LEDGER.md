## Verification ledger

- Source comparison: **VERIFIED** for the files above and the pinned heads.
- Flutter implementation: **IMPLEMENTED, NOT DEVICE-VERIFIED** for Nunito, floating liquid navigation, fallback progressive blur, glass sheets, tab transitions, collapsing profile header, pull resistance, ticker, travelling avatar, full-screen Passport, Home ring and trend, Profile medals/snapshots/histogram, History heatmap, Scan targeting/shutter, and Guide/Results/Settings selection controls. These are independent implementations; no GymMane GPL code or shader was copied.
- Home: the ring and seven-day chart use only saved ratings. The ring remains unknown when a rating is missing. Widget tests cover empty and recorded values, including large text.
- Profile: the medal shelf, snapshots and 12-month bars use the loaded account records. When only an offline cache is available, the Passport labels the count as cached. Snapshot cards use a scan icon when no image is present in the Flutter history contract.
- History: the 30-day heatmap uses actual record dates and available ratings. It does not color an unrated day as clean. Clear-all calls the existing account repository only after confirmation; no backend contract changed.
- Results: the numeric ring uses the same visual primitive as Home, and missing ratings remain unknown. Ingredient analysis is merged into one list to avoid duplicate cards. Guide never labels an unknown additive risk as safe.
- Automated tests: **VERIFIED** locally with `flutter analyze` (zero issues), `dart format --output=none --set-exit-if-changed lib test` after formatting, and `flutter test --concurrency=2` (53 passed, zero failed) on 2026-11-17. These prove widget and adapter behavior under the test fixtures; they do not prove device motion or a live scan.
