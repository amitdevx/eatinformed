# Motion architecture and GymMane comparison

Reference: local App Designs/GymMane. Profile source accumulates pointer deltas with resistance, checks scroll-top, reaches 210 points, haptics once armed, then opens recap. Content follows 55% of pull while fading; ticker and traveller derive from normalized progress. Traveller uses viewport geometry and a curved orbit. Ticker painter measures text. ScrollAway measures position, using depth .08, follow .18, dim .45 and lead 64. Entrance uses 560ms cubic exit easing, 22px and .97 scale; shimmer makes one 1300ms pass. Glass manages native filtering, sheet recession and overscroll dismissal. Liquid notch uses measured rectangles and custom paths with 650/450ms transitions. Rolling text, medals and recap have independent controllers and cleanup.

EatInformed independently implements ProfileReveal using Gesture Handler 2.32 and Reanimated 4.5.1 / Worklets .10.1, selected by Expo SDK57 installation. One normalized progress drives content/ticker/avatar. Native scroll waits for pan failure; downward top-only intent activates pan. Edges and horizontal movement reject. Measured source coordinates feed an independently written curved avatar transition. Passport stays within the screen and targets BlurTargetView with dimezisBlurView. Back, close, backdrop and focus/background cleanup are supported. Shared motion tokens, reduced-motion subscription, entrance and measured optional scroll depth live in theme/motion and animations. Idle FAB pulse removed; ticker only runs during visible interaction, measures period, and stops on background.

Differences: threshold is 210 raw finger points, not Flutter's resisted accumulated distance; avatar path is independently implemented; shader/liquid effects and full recap storytelling are not reproduced. Broad animation parity, true Android blur, rendered FPS and haptic timing are NOT TESTED. Exact blue scrolling effect remains unidentified without a running reference. No copied Flutter code or artwork was introduced. GymMane GPL-3.0-only and additional attribution terms were read; functional concepts were independently implemented. This is not a legal conclusion about distribution obligations.
